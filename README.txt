시세봄 16단계 - 검색 스니펫 가격 순서 수정

15단계에서 2만원 같은 너무 낮은 가격은 잡혔지만,
설명 안의 여러 가격 중 가장 큰 값을 선택하면서
일부 당근 매물이 130만원, 230만원처럼 부풀려지는 문제가 생겼습니다.

이번 수정:
- 제목에 가격이 있으면 제목의 첫 현실 가격 사용
- 제목에 가격이 없으면 검색 설명에 나온 순서대로
  첫 번째 현실적인 가격 사용
- 모델별 최소 현실가격 필터는 그대로 유지
- '가장 큰 가격 선택' 로직 제거

적용:
1. ZIP 압축 해제
2. server 폴더를 기존 sisebom 폴더에 덮어쓰기
3. GitHub Desktop Summary:
   검색 스니펫 가격 순서 수정 16단계
4. Commit to main
5. Push origin
