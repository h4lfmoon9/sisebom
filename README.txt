시세봄 25단계 - 중고매물 첫 번째 사진

요청한 기능:
'사진 없음' 대신 각 원본 중고매물 페이지의 첫 번째 상품 사진을 카드에 표시합니다.

동작:
- 이미 사진이 잡힌 매물은 그대로 사용
- 사진이 없는 정상 매물만 원본 공개 페이지를 한 번 확인
- og:image / twitter:image / image_src / 공개 JSON-LD의 첫 사진을 사용
- 번개장터는 원본 product ID와 이미지 product ID가 정확히 같을 때만 허용
- 당근/중고나라도 원본 페이지의 대표 이미지 메타데이터만 사용
- 로고/기본 OG 이미지/프로필 같은 사이트 이미지는 제외
- 원본 페이지가 403/차단/시간초과면 우회하지 않고 '사진 없음' 유지
- 이미지 결과는 서버 메모리에 30분 캐시해서 반복 요청을 줄임

속도:
- Tavily 최대 대기 6.5초
- 원본 사진 확인 최대 1.4초
- 사진 확인은 매물별 병렬 실행
- 기존 server.js의 플랫폼 9초 제한 안에 들어오도록 조정

적용:
1. ZIP 풀기
2. server 폴더를 기존 sisebom 폴더에 덮어쓰기
3. GitHub Desktop Summary:
   중고매물 첫 사진 표시 25단계
4. Commit to main -> Push origin

배포 후:
아이폰 15 검색 -> 매물 새로고침
사진을 공개적으로 읽을 수 있는 매물은 실제 첫 사진이 표시됩니다.
플랫폼이 원본 HTML을 막는 매물은 '사진 없음'으로 남는 것이 정상입니다.
