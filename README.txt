시세봄 관리자 V1

1. 이 ZIP을 시세봄 프로젝트 최상단(server 폴더가 있는 곳)에 풉니다.
2. 시세봄-관리자-설치.bat 실행
3. http://127.0.0.1:3131 관리자 화면이 열립니다.
4. 이후 Windows 로그인 시 자동 실행됩니다.

관리자 기능:
- 시세봄 켜기/끄기/재시작
- 오류 로그 확인
- 업데이트 ZIP 업로드
- 업데이트 전 자동 백업
- apply-*.js 자동 실행
- 업데이트 후 자동 재시작

GitHub는 필요 없습니다.
중요: ChatGPT가 사용자의 PC에 직접 파일을 밀어넣을 수는 없습니다.
대신 내가 만든 업데이트 ZIP을 관리자 화면에 올리면 그 뒤 적용/백업/재시작은 자동입니다.
