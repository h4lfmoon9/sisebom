시세봄 24단계 - 매물 사진·지역 정보 보강

이번 단계는 실제 매물 카드의 빈 정보 보강입니다.

변경:
- 번개장터 검색 스니펫에 현재 상품의 media.bunjang.co.kr 이미지가 있으면 썸네일 표시
- 반드시 현재 번개 상품 ID와 이미지 URL의 product ID가 같을 때만 사용
- 추천상품/다른 상품 이미지는 사용하지 않음
- 당근 공개 페이지의 'OO 근처 인기 중고거래' 구조에서 지역 표시
- 번개장터 '직거래 장소'가 있으면 지역 표시
- 중고나라도 명시적인 거래 지역이 있을 때만 표시
- 확실하지 않은 이미지/지역은 기존처럼 빈 값으로 유지

안전 원칙:
- 임의 이미지 생성/대체 안 함
- 다른 매물 이미지를 현재 매물 사진처럼 표시 안 함
- 추측한 지역 표시 안 함
