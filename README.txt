시세봄 완전 재구축 복구본

설치 방법
1) 파트 1~4 ZIP을 모두 같은 sisebom 폴더에 풀어 주세요.
2) 기존 파일과 겹치면 '대상 폴더의 파일 바꾸기'를 선택하세요.
3) GitHub Desktop에서 변경 파일을 모두 체크합니다.
4) Summary: 시세봄 전체 재구축
5) Commit to main → Push origin

중요
- 색상 버튼 기능은 제거되어 있습니다.
- 모델마다 대표 이미지 1장만 표시합니다.
- 이번 복구본은 서버 오류에 영향받지 않도록 프론트엔드에서 자체 동작합니다.
- 통합 매물은 현재 샘플 데이터입니다.
- 사용자가 제공한 이미지 파일만 포함했습니다.
