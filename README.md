# 시세봄 - iPhone 15 통합검색 프로토타입

지금까지 구상한 내용을 한 화면에 합친 테스트 버전입니다.

## 반영된 기능
- 초록 계열 브랜드 디자인
- 메인 카피: AI로 분석 / 중고 매물부터 / 시세까지 한 번에
- AI만 초록색
- '분/석' 위 초록 포인트 점
- 당근 / 번개장터 / 중고나라 통합 매물 구조
- iPhone 15 검색 시 128GB / 256GB / 512GB 모두 표시
- 용량 필터
- 플랫폼 필터
- 가격 범위 필터
- 최저가순 / 최고가순 / 최신순
- 최저가 / 평균가 / 최고가
- 구매점수 색상 기준
  - 70~100 초록
  - 40~69 노랑
  - 0~39 빨강
- AI 구매 판단 예시
- 당근 '바로구매' 배지
- 원본 매물 보기 버튼
- iPhone 15 색상 / 디자인 / 제품 정보
- 성능점수
- 제품 비교하기 예시

## 주의
현재 매물과 가격은 UI 테스트용 가상 데이터입니다.
실제 공개 서비스에서는 각 플랫폼의 허용된 공개 데이터 연결 방식이 필요합니다.


## Layout v2 변경사항
- 시세분석을 왼쪽 열로 배치
- 제품정보를 오른쪽 열로 배치
- 통합매물을 그 아래 전체 가로폭으로 확장
- 데스크톱에서 통합매물 카드 최대 4열
- 제품정보에 `AI로 비교하기` 버튼 추가
- 기존 디자인/필터/구매점수/AI 분석 로직은 유지


## 변경사항
- v2 레이아웃 기준
- 큰 `시세 분석` 제목 제거
- 큰 `제품 정보` 제목 제거
- 큰 `아이폰 15` 제목 제거
- 나머지 카드, 필터, 시세/제품정보 기능은 그대로 유지


## clean top 변경사항
- MARKET ANALYSIS 삭제
- '현재 검색된 매물 가격을 기준으로 분석합니다.' 삭제
- 상단 '구매하기 좋은 편' 배지 삭제
- '12개 테스트 매물 분석 중' 삭제
- PRODUCT INFO 삭제
- 제품정보 설명 문구 삭제
- 시세분석/제품정보 두 영역의 시작 높이를 동일하게 정렬


## 공식 출시가 추가 버전
- v2 상단 정리 레이아웃 기준
- 성능점수와 공식 출시가를 같은 크기의 2개 카드로 나란히 배치
- iPhone 15 공식 출시가 예시:
  - 128GB: 1,250,000원
  - 256GB: 1,400,000원
  - 512GB: 1,700,000원
- 용량 필터를 누르면 공식 출시가도 해당 용량 기준으로 자동 변경
- 전체 선택 시 128GB 기준 시작가 표시
- 성능 세부 막대와 버튼 정렬 개선
- 상단 제목 제거 후 남아 있던 JS 참조 오류도 함께 수정


## 출시일 카드 추가
- 성능점수 / 공식 출시가 / 출시일을 동일한 카드 크기로 한 줄 배치
- iPhone 15 출시일 예시: 2023.09
- 모바일에서는 1열로 자동 배치


## 출시일 별도 카드 버전
- 출시일을 성능점수 카드 안에서 제거
- 제품 이미지 옆의 남는 공간에 별도 카드로 배치
- 성능점수 카드에는 성능점수 + 공식 출시가만 유지
- 모바일에서는 출시일 카드가 아래로 자동 이동


## 성능점수 전체 가로폭 배치
- 출시일 카드 제거
- 제품 이미지 카드 다시 전체폭 사용
- 성능점수 카드를 시세분석/제품정보 두 열 아래 전체폭으로 이동
- AI 구매판단 아래부터 오른쪽 끝까지 한 줄 폭으로 확장
- 공식 출시가 유지
- 일상/게임/카메라 세부 점수는 기존 세로 목록 유지
