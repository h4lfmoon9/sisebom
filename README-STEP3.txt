시세봄 - 당근 + 번개장터 + 중고나라 실제 매물 연결 3단계

추가 사항
- 당근 공개 중고거래 검색 페이지 연동
- 당근 + 번개장터 + 중고나라 결과 통합
- 예약중 / 판매완료 / 거래완료 제외
- 삽니다 / 구해요 / 매입 글 제외
- 명백한 케이스 / 필름 등 액세서리 제외
- 실제 가격 / 용량 / 썸네일 / 원본 링크 사용
- 한 플랫폼 오류 시 나머지 플랫폼 결과는 계속 표시

당근 참고
- 당근 웹 검색은 위치 기반이라 공개 페이지에서 노출되는 결과도 위치 범위의 영향을 받을 수 있습니다.
