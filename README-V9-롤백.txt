시세봄 사이트 복구 V9 롤백

V9 적용 후 localhost:3000 자체가 접속되지 않을 때 사용합니다.

방법 1 - 시세봄 관리자(127.0.0.1:3131)가 열리는 경우
1) 이 ZIP을 '업데이트 ZIP'에 선택
2) 업데이트 적용
3) 관리자가 적용 후 시세봄 서버를 다시 시작합니다.

방법 2 - 관리자도 안 열리는 경우
1) 이 ZIP을 현재 시세봄 프로젝트 최상단에 풉니다.
2) V9-롤백.bat 실행
3) 기존 '시세봄-서버-켜기.bat'를 다시 실행합니다.

이 롤백은 V9가 만든
*.before-site-repair-v9.bak
파일을 찾아 원래 server.js / script.js로 복원합니다.
