시세봄 FINAL V8.1 - 중고나라 페이지네이션 / 최대 매물 수집 보강

적용 방법
1. ZIP을 시세봄 저장소 최상단에 풀어서 덮어쓰기
2. 저장소 최상단 터미널에서: node apply-final-v8-1.js
3. 테스트: cd server && npm test
4. GitHub Desktop Commit -> Push

핵심 변경
- 중고나라 검색 결과를 첫 화면만 읽지 않고 ?page=1,2,3... 마지막 공개 페이지까지 순차 수집
- 검색 페이지의 '총 N개'를 읽어 예상 마지막 페이지를 계산
- 페이지에 새 상품이 계속 있으면 계속 수집
- 빈/중복 페이지가 연속되면 안전 종료
- 플랫폼당 기본 안전 상한 20,000개 (SISEBOM_MAX_LISTINGS로 최대 50,000개)
- 중고나라 최대 페이지 기본 1,000페이지 (SISEBOM_JOONGNA_MAX_PAGES로 최대 2,000페이지)
- 심층 작업 기본 30분 (SISEBOM_DEEP_JOB_MAX_MS로 최대 2시간)
- 프론트는 수집중이면 최대 약 45분 동안 주기적으로 새 스냅샷 확인
- 용량은 검색/필터 조건으로 사용하지 않고 매물 메타데이터로만 표시

주의
- 공개 페이지가 403/429 등으로 접근을 제한하는 경우 이를 우회하지 않는다.
- 실제 수집 개수는 각 사이트가 공개 웹에서 노출하는 범위와 서버 시간 제한에 따라 달라질 수 있다.
