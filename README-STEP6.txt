시세봄 중고매물 6단계 - 실제 시세 계산 정교화

변경사항
- 당근 + 번개장터 + 중고나라 실제 판매중 매물을 기준으로 시세 계산
- 가격 극단값(IQR 방식)은 매물 목록에서는 유지하지만 최저가/평균가/최고가 계산에서만 제외
- 시세 계산에 실제 사용한 매물 수 표시
- 구매점수도 실제 매물 가격 분포, 표본 수, 새제품 가격, 성능점수를 함께 반영
- 각 매물의 평균 대비 저렴/비쌈 표시도 정제된 시세 평균 기준
- 예약중/판매완료/거래완료 제외 및 정확한 모델 필터 유지

설치
1. 압축을 풉니다.
2. index.html, script.js를 기존 sisebom 폴더에 덮어씁니다.
3. GitHub Desktop에서 커밋 후 Push origin 합니다.
