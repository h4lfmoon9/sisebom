시세봄 FINAL V8 - 최대 매물 수집

변경사항
- 중고매물 검색에서 용량 조건 제거
- 128GB/256GB/512GB로 검색을 나누지 않음
- 용량은 매물 제목/본문에 실제로 적혀 있을 때만 표시용으로 기록
- 아이폰15는 아이폰15 / iPhone 15 등 넓은 모델 검색어로 수집
- 당근/번개장터/중고나라 각각 새 매물이 더 나오지 않을 때까지 스크롤/더보기 반복
- 정상 종료 기준: 5회 연속 새 매물 없음
- 안전 상한: 플랫폼당 5,000개 (SISEBOM_MAX_LISTINGS로 최대 10,000 조정 가능)
- 스크롤 안전 상한: 기본 240회
- 심층 수집 안전시간: 기본 15분
- 로그인/차단 우회는 하지 않음

적용
1. ZIP을 시세봄 저장소 최상단에 압축 해제
2. node apply-final-v8.js
3. cd server && node --test qa/v8MaxListings.test.js
4. GitHub Desktop Commit -> Push
