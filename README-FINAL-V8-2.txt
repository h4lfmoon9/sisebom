시세봄 FINAL V8.2 - 중고나라 실제 동적 로딩 수집 보강

핵심 변경
- 중고나라 검색을 ?page=N 이라고 가정하던 방식을 제거했습니다.
- 검색 페이지 HTML에 직렬화된 items 데이터가 있으면 직접 읽습니다.
- 페이지가 실제로 사용하는 공개 XHR/fetch JSON 응답에서 상품 레코드를 자동 인식합니다.
- 화면 스크롤, 더보기, End 이동을 반복하면서 새 매물이 계속 들어오면 계속 수집합니다.
- 여러 경로에서 같은 매물을 발견해도 상품 URL로 중복 제거합니다.
- 중고나라가 표시하는 총 검색 개수도 가능한 경우 상태값으로 읽습니다.
- 128/256/512GB 등 용량은 검색 조건으로 사용하지 않습니다. 매물 자체에 적혀 있을 때만 메타데이터로 표시합니다.

수집 한도
- 플랫폼당 기본 안전 상한: 20,000개
- SISEBOM_MAX_LISTINGS 환경변수로 최대 50,000개
- 심층 수집 기본 최대 시간: 45분
- SISEBOM_DEEP_JOB_MAX_MS 환경변수로 최대 2시간
- 중고나라가 연속 12회 동안 새 매물/새 로딩을 전혀 만들지 않으면 자연 종료

적용
1. ZIP 내용을 시세봄 저장소 최상단에 덮어쓰기
2. node apply-final-v8-2.js
3. cd server && npm test
4. GitHub Desktop Commit / Push

주의
중고나라가 실제로 공개하는 결과 수, 로딩 구조, 접속 제한에 따라 최종 수집 개수는 달라질 수 있습니다.
