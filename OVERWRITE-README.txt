시세봄 iPhone 클래식 배치1 전체 수정판

이번 버전은 사진이 안 뜨는 문제를 함께 수정했습니다.

포함 이미지:
- iPhone 1세대
- iPhone 3G
- iPhone 3GS
- iPhone 4
- iPhone 5
- iPhone 6
- iPhone 7
- iPhone 8
- iPhone X
- iPhone XR

핵심 수정:
- 이미지 10개를 프로젝트 내부에 직접 포함
- apple.json 이미지 경로 연결
- Render가 아직 예전 데이터를 반환해도 script.js가 모델 ID로 로컬 이미지를 직접 찾음
- GitHub Pages 경로 기준으로 이미지 URL을 명확하게 처리

적용:
1. ZIP 압축 해제
2. 안의 모든 파일/폴더를 기존 Documents/GitHub/sisebom 안에 덮어쓰기
3. 기존 sisebom 폴더 자체나 .git 폴더는 삭제하지 않기
4. GitHub Desktop Summary: 아이폰 클래식 이미지 로딩 수정
5. Commit to main
6. Push origin
7. Render 배포 완료 후 사이트에서 Ctrl + F5
