시세봄 클래식 iPhone 색상 로딩 수정판

이번 수정은 색상별 새 PNG 수십 장을 불러오는 방식을 없앴습니다.
각 모델의 기존 누끼 PNG 1장을 브라우저가 직접 색상 변환합니다.
그래서 GitHub Pages에서 색상별 파일 404가 나서 이미지 로딩 실패가 뜨는 문제를 피합니다.

색상 포함:
- iPhone: 실버
- 3G/3GS/4: 블랙, 화이트
- 5: 블랙&슬레이트, 화이트&실버
- 6: 스페이스 그레이, 실버, 골드
- 7: 블랙, 제트 블랙, 실버, 골드, 로즈 골드, 레드
- 8: 스페이스 그레이, 실버, 골드, 레드
- X: 스페이스 그레이, 실버
- XR: 블랙, 화이트, 블루, 옐로, 코랄, 레드

적용: ZIP 내용 전체를 기존 sisebom 폴더 안에 덮어쓰기 → Commit → Push → Ctrl+F5
